Support

PleatView is a free, open-source project by Hustlesman. Here's how to get help.

Setting up? Follow the install guide: three steps, no computer needed for the TV.
Something wrong? Open an issue on GitHub.
Something private (privacy, a donation, a security problem)? Email privacy@hustlesman.com.

Common questions

Home Assistant asks me to connect GitHub

On Home Assistant 2026.11 and later, PleatView comes from the built-in Marketplace. Until it's in the Marketplace catalogue, adding it from GitHub needs a GitHub connection once: choose Connect GitHub, enter the code shown at github.com/login/device, then open the PleatView link again. The connection only reads public information.

Does it work on Fire TV?

Yes. Install Downloader from the Amazon Appstore and enter pleatview.hustlesman.com/apk. Fire TV sticks on Fire OS 7 run Android 9, where pictures in notifications show their first frame instead of animating. An Amazon Appstore listing is on the roadmap.

How do I know the app is genuine?

Every PleatView release is signed with the same key, and Android checks it on every update, so only a genuine PleatView can update the one you installed. The key's SHA-256 fingerprint is:

27:7B:CC:FA:72:E6:00:CE:D2:58:EF:9B:C4:DE:43:C6:FA:2F:27:53:8A:98:59:B2:C6:F2:EC:7C:34:3A:E3:73

To check a downloaded APK yourself, run apksigner verify --print-certs pleatview.apk. The same fingerprint is published in assetlinks.json, which ties this website to the app.

Home Assistant doesn't find the TV

Open PleatView on the TV first. Discovery doesn't cross separate networks or VLANs. If yours are split, add the PleatView integration manually in Home Assistant (Settings → Devices & services → Add integration) with the address shown on the TV.

The TV says Home Assistant rejected the access token

In Home Assistant, open the PleatView integration and choose Reload from its ⋮ menu; it issues a new token. If you use your own long-lived token, enter a new one with Reconfigure.

Home Assistant can't bring PleatView to the front, or notifications only show while it's open

Android only allows this for apps that may display over other apps. Open PleatView's menu (press Back on the home dashboard) and choose Allow display over other apps. If your TV has no such setting, which is common on Google TV, grant it once from a computer:

adb shell appops set com.hustlesman.pleatview SYSTEM_ALERT_WINDOW allow

The screen still goes dark or the screensaver starts

PleatView keeps the screen on while a dashboard is showing. The TV's own sleep timer and energy-saving settings can still switch the panel off; set them to never for a permanent display.

A dashboard asks me to sign in

Scan the code on the TV with your phone and sign in there. The TV saves the sign-in once the site accepts it and signs in again by itself after that. It keeps it encrypted on the TV only, for that one site. To remove it, press Back on the home dashboard and choose Forget saved sign-ins. Sites with two-step sign-in or a CAPTCHA still need you to finish on the TV with the remote.

A camera doesn't play

Live video needs Home Assistant's stream integration, which is part of the default configuration. Cameras that can't stream are shown as a sequence of still images instead.

I cleared PleatView's data or reinstalled it

Home Assistant notices and asks for the new PIN under Settings → Devices & services. After that, all settings come back automatically.

How do I remove PleatView?

Remove the integration in Home Assistant, which deletes the user it created and resets the TV. Then uninstall the app on the TV.

Reporting a problem

Open an issue on GitHub and include:

  • your TV or streaming device and its Android TV version,
  • the PleatView version (in its menu: press Back on the home dashboard),
  • your Home Assistant version,
  • what you did, what you expected, and what happened instead.

PleatView is maintained in spare time. We reply as soon as we can, usually within a few days.
